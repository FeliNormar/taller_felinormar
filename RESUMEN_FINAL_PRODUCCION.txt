  🚀 CÓMO INICIAR
═══════════════════════════════════════════════════════════════════════════════

1. DESARROLLO LOCAL:
   
   export FLASK_ENV=development  # Linux/Mac
   set FLASK_ENV=development     # Windows
   
   python wsgi.py
   
   Accede a: http://localhost:5000

2. GENERAR SECRET_KEY:
   
   python -c "import secrets; print(secrets.token_hex(32))"

3. CONFIGURAR .env:
   
   cp .env.example .env
   # Editar .env y pegar SECRET_KEY generada

OPCIÓN 1: RENDER (Recomendado - Free tier)
   1. Push a GitHub: git push origin main
   2. Crear Web Service en render.com
   3. Conectar repositorio
   4. Configurar variables:
      SECRET_KEY=<tu-clave-generada>
      FLASK_ENV=production
   5. Deploy automático

OPCIÓN 2: RAILWAY
   1. Push a GitHub: git push origin main
   2. New Project en railway.app
   3. Deploy from GitHub repo
   4. Configurar SECRET_KEY en Variables
   5. Deploy automático

OPCIÓN 3: VPS (Ubuntu + Nginx)
   Ver guía completa en: docs/DEPLOYMENT.md
