# Carpeta de Imágenes

## Logo del Sistema

Para que el sistema muestre correctamente el logo de Felinormar, debes colocar la imagen del logo en esta carpeta con el nombre:

```
logo.png
```

### Especificaciones del Logo:
- Nombre del archivo: `logo.png`
- Formato recomendado: PNG con fondo transparente
- Dimensiones recomendadas: 400x400 px o superior (cuadrado)
- El logo debe ser la imagen de Felinormar (celular con fénix en llamas azules)

### Ubicación:
El logo se mostrará en:
- Pantalla de login (120x120 px)
- Sidebar del sistema (40x40 px)

Una vez colocado el archivo `logo.png` en esta carpeta, el sistema lo cargará automáticamente.
